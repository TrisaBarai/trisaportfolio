# Resume Directory

This folder contains your resume file for your portfolio website.

## How to update your resume:
1. Export your real resume as a PDF file named `resume.pdf`.
2. Copy and paste your `resume.pdf` into this `resume/` folder (replacing the placeholder).
3. Also copy `resume.pdf` to the root folder if desired.
4. Your website's **Download Resume** buttons will automatically serve your new resume!

Fake Review Detection System

This project is an AI-based system designed to identify whether an online review is genuine or fake. It analyzes review information and uses machine learning techniques to classify suspicious reviews.

Key Project Features:

  • NLP Preprocessing: Cleans text, removes noise/stopwords, and extracts term frequency features.
  • Machine Learning Classifier: Classifies reviews into Genuine vs. Fake with confidence percentages.
  • Flask REST API: High-performance Python backend managing review classification requests.
  • SQL Database Integration: Stores analyzed logs, prediction results, and user feedback.

# Fake Review Detection System - Backend (Flask + SQLite)

This folder contains a lightweight Python Flask backend API that can analyze reviews and store analysis results in an SQLite database.

## How to run the backend:

1. Open your terminal in this `backend/` folder:
   ```bash
   cd backend
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the Flask application:
   ```bash
   python app.py
   ```

4. The API will be live at `http://127.0.0.1:5000/api/analyze`.
